Какие данные обрабатывает ForestPoint

  • Данные аккаунта — при входе через Google могут использоваться имя, адрес электронной почты и идентификатор Google для авторизации.
  • Геолокация — используется для определения текущего положения на карте, поиска ближайших грибных наблюдений и формирования локального прогноза. ForestPoint не осуществляет фоновое отслеживание местоположения.
  • Локальные данные — ваши приватные точки, описания и настройки могут храниться локально на вашем устройстве.
  • Публичные точки — если вы самостоятельно выбираете «Поделиться с сообществом», соответствующая точка может быть сохранена в Firebase Firestore и показана другим пользователям ForestPoint.
  • Данные о погоде — погодная информация может запрашиваться для обработки грибных наблюдений и отображения соответствующей информации пользователю.

What data ForestPoint processes

  • Account data — when signing in with Google, your name, email address and Google identifier may be used for authentication.
  • Location — used to show your position on the map, find nearby mushroom observations and provide a local mushroom activity forecast. ForestPoint does not perform background location tracking.
  • Local data — your private points, descriptions and settings may be stored locally on your device.
  • Public points — when you explicitly choose "Share with community", the corresponding point may be stored in Firebase Firestore and displayed to other ForestPoint users.
  • Weather data — weather information may be requested to process mushroom observations and provide relevant information to users.
🍄

Данные из внешних источников

ForestPoint агрегирует общедоступную информацию из нескольких внешних источников, чтобы формировать обзор недавней активности грибов.

  • Географические данные — для определения приблизительного местоположения, указанного в публичных публикациях, могут использоваться сервисы геокодирования, включая Nominatim / OpenStreetMap.

Data from external sources

ForestPoint aggregates publicly available information from multiple external sources to provide an overview of recent mushroom activity.

  • Geographic data — geocoding services, including Nominatim / OpenStreetMap, may be used to identify approximate locations mentioned in public posts.
🔄

Публичные и приватные точки

По умолчанию все создаваемые пользователем точки являются приватными и хранятся локально на устройстве.

Пользователь может самостоятельно сделать точку публичной, выбрав «Поделиться с сообществом». Только после этого точка может быть загружена в Firebase Firestore и показана другим пользователям.

Пользователь может удалить свои публичные точки через приложение.

Public vs Private points

By default, all points created by a user are private and stored locally on the device.

A user can choose to make a point public by selecting "Share with community". Only then may the point be uploaded to Firebase Firestore and displayed to other users.

Users can delete their public points through the application.

🗄️

Где хранятся данные

  • Локальное хранилище на устройстве пользователя.
  • Firebase Authentication — для авторизации.
  • Firebase Firestore — для публичных пользовательских точек.
  • Серверная обработка ForestPoint / Firebase Cloud Functions — для получения и обработки данных внешних источников, необходимых для работы прогноза.

Where data is stored

  • Local storage on the user's device.
  • Firebase Authentication — for authentication.
  • Firebase Firestore — for public user-submitted points.
  • ForestPoint server-side processing / Firebase Cloud Functions — for retrieving and processing external-source data required for the forecast.
🚫

Что мы НЕ делаем

  • Не продаём персональные данные.
  • Не используем данные ForestPoint для персонализированной рекламы.
  • Не отслеживаем геолокацию в фоновом режиме.
  • Не публикуем контент в Threads от имени пользователя.
  • Не публикуем посты и комментарии в Reddit от имени пользователя.
  • Не используем Threads API для управления профилем пользователя, публикации, ответов или модерации.

What we do NOT do

  • We do not sell personal data.
  • We do not use ForestPoint data for personalized advertising.
  • We do not track location in the background.
  • We do not publish Threads content on behalf of users.
  • We do not publish Reddit posts or comments on behalf of users.
  • We do not use the Threads API to manage user profiles, publish content, reply to posts, or perform moderation.
🗑️

Удаление данных

Пользователь может удалить свой аккаунт и связанные с ним данные непосредственно в приложении:

Настройки → Аккаунт → Удалить аккаунт

При удалении аккаунта публичные точки пользователя удаляются из Firebase Firestore. Локальные данные приложения могут быть удалены вместе с данными приложения на устройстве.

Для вопросов, связанных с удалением данных или конфиденциальностью, пользователь также может обратиться по адресу ниже.

Data deletion

Users can delete their account and associated data directly in the application:

Settings → Account → Delete account

When an account is deleted, the user's public points are removed from Firebase Firestore. Local application data may be removed with the application data stored on the device.
